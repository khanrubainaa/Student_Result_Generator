
# Project 9 - Student Result Generator

A simple Python application that generates a student's result based on marks in five subjects.

## Features
- Accepts student name and marks for five subjects.
- Calculates total marks.
- Calculates percentage.
- Assigns grades (A, B, C or Fail).
- Displays a formatted result report.
- Saves the result in result.txt.

## Concepts Used
- Lists
- Functions
- For loops
- If-elif-else statements
- Type casting
- File handling
- F-strings

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run: python student_result.py
